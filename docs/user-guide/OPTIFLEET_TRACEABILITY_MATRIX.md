## Catatan Metodologi

- Kolom **Test** hanya mencantumkan nama file/suite pengujian yang ditemukan secara langsung merujuk pada fitur tersebut, bukan estimasi. Baris tanda `—` berarti tidak ditemukan file test khusus untuk fitur tersebut dalam cakupan pemeriksaan sesi ini (bukan berarti pasti tidak ada — lihat `Unverified` bila relevan).
- Seluruh path file bersifat relatif terhadap root repository (`/home/user/OptiFleet`).
- Untuk daftar 275 permission lengkap per baris, rujuk langsung `backend/database/seeders/PermissionSeeder.php` — tidak diduplikasi penuh di sini agar dokumen ini tetap dapat dibaca.
