# Authorization route matrix

_Generated by `php artisan optinexus:route-matrix` from the live route table; `tests/Feature/Governance/AuthorizationRouteMatrixTest` fails when this file is stale. Do not edit by hand._

Every `/api/v1/app/*` request passes, in order: Sanctum session, `TenantContextMiddleware` (tenant status; for a centrally governed tenant also the SSO-session check and the OptiNexus access snapshot, which fail closed), `EnsureTenantScope`, the module gate (entitlement; for a centrally governed tenant the capabilities OptiNexus holds), the permission gate (`CheckPermission` -> `PermissionService`; for a centrally governed tenant the OptiNexus grants, narrowed by local roles), then the controller/service checks (data scope, ownership, accounting invariants). Routes marked `not.central` refuse to mint local users or entitlements in a centrally governed tenant (409 `GOVERNED_CENTRALLY`). Exports, downloads and uploads are ordinary routes of this table; background jobs and streams re-check the entitlement through `ChecksCentralEntitlement` / `EntitlementService`.

Routes: 812 method+path pairs. By gate: tenant session + permission + module 633; platform session + permission 123; tenant session + permission 31; tenant session + check in controller 11; session only 7; public 6; feed credential 1.

Routes with the check inside the controller (`IN_CONTROLLER`): 11 (configuration versions/restore, dashboard, workflow available-transitions); they call `PermissionService` / `EntitlementService`, the same central resolver.
